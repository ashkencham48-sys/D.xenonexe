👑 The D.XENO.EXE Brand Identity

D.XENO.EXE is a personalized anime and shadow gaming system featuring the user's authentic identity at its center. Engineered with zero external library bloat, procedural Web Audio, and responsive CSS grids, it delivers high performance on Android mobile devices, tablets, and desktop workstations.

📱 1. Android HopWeb Setup Instructions

To run, edit, or test this complete website on Android using the HopWeb mobile code editor:

  1. Install HopWeb from Google Play Store or APK mirror.
  2. Create a new project named D.XENO.EXE.
  3. Copy the folder structure: index.html at root, plus css/, js/, and assets/.
  4. Place your photograph as assets/dxeno_photo.png.
  5. Tap the Run / Preview button in HopWeb to launch the interactive site instantly on your phone with local storage and audio support!

🚀 2. Free Netlify Deployment Instructions

Deploy in 30 seconds with 100% free SSL and instant global CDN:

  1. Visit app.netlify.com/drop in any browser.
  2. Drag and drop the folder containing index.html, css/, js/, and assets/ directly into the upload area.
  3. Netlify will instantly generate a live public URL (e.g. dxeno-exe.netlify.app).
  4. Optional: Go to Site Settings > Change site name to customize your domain to dxeno-exe.netlify.app.

🐙 3. Free GitHub Pages Deployment

Host directly from a free GitHub repository:

  1. Create a new public GitHub repository named dxeno-exe.
  2. Push or upload index.html, css/, js/, and assets/ to the main branch.
  3. In your repository, navigate to Settings > Pages.
  4. Under Branch, select main and folder / (root), then click Save.
  5. Your site is live within 60 seconds at https://yourusername.github.io/dxeno-exe/!
